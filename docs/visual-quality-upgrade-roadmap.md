# Gloambound 그래픽 품질 개선 로드맵

## 현재 상태와 핵심 진단

현재 캐릭터와 배경은 기본 도형을 조립해 형태와 배치를 검증하는 블록아웃 단계다. 이 방식은 전투 구도와 게임 로직을 빠르게 시험하는 데는 적합하지만, 도형의 수를 늘리거나 조명만 강화하는 것으로는 실사 또는 고품질 만화풍에 도달하기 어렵다.

품질을 확실히 높이려면 모델 제작 방식을 다음과 같이 전환해야 한다.

- 기본 도형 조립에서 설정화 기반 스컬프팅으로 전환
- 단색 재질에서 PBR 또는 손으로 그린 셀 셰이딩 재질로 전환
- 단순 관절 회전에서 리깅된 전신 애니메이션으로 전환
- 단일 배경 메시에서 모듈식 환경과 소품·데칼·파티클 조합으로 전환

## 권장 목표: 독자적인 다크 만화풍 3D

이 프로젝트에는 실사보다 어두운 만화풍 3D가 현실적인 목표다. 실사는 피부, 모발, 천, 얼굴 표정과 애니메이션의 작은 결함도 크게 드러나며 웹 렌더링 비용도 높다. 반면 만화풍은 과장된 실루엣, 제한된 색상, 명확한 명암과 외곽선으로 분위기와 가독성을 함께 확보할 수 있다.

기존 작품의 고유한 캐릭터·UI·화풍을 그대로 복제하지 않고, Gloambound만의 형태 언어와 색상 체계를 설계한다.

## 1. 설정화와 아트 기준 확정

모델링 전에 각 캐릭터와 주요 배경의 제작 기준을 이미지로 확정한다.

캐릭터 설정화에는 다음 내용을 포함한다.

- 정면·측면·후면 턴어라운드
- 얼굴, 손, 무기와 장비 확대도
- 기본 자세와 전투 자세
- 색상표와 재질 구분
- 키, 어깨 폭, 머리 크기 등 비율 기준
- 손상, 오염, 문양과 장식의 위치

배경 설정화에는 다음 내용을 포함한다.

- 전투 카메라에서 본 전체 구도
- 전경·중경·후경 구분
- 조명 방향과 색상
- 반복 사용될 건축 모듈과 소품
- 바닥, 벽, 금속, 목재의 재질표

## 2. 캐릭터 모델링 파이프라인

1. 인체 또는 생물형 베이스 메시를 준비한다.
2. Blender Sculpt Mode에서 얼굴, 근육, 옷 주름과 실루엣을 조형한다.
3. 갑옷, 가죽 장비, 무기와 장식은 별도 메시로 제작한다.
4. 리토폴로지로 변형에 적합한 게임용 메시를 만든다.
5. UV를 전개하고 고해상도 조형의 세부 정보를 노멀맵으로 굽는다.
6. 손으로 그린 색상과 PBR 재질 정보를 제작한다.
7. 게임용 리그와 표정·무기 제어 본을 구성한다.

초기 웹 목표치는 다음 범위에서 시작한다.

- 주요 영웅: 약 20,000~40,000 triangles
- 일반 적: 약 10,000~25,000 triangles
- 주요 캐릭터 텍스처: 2K 한 세트
- 군중 또는 원거리 소형 개체: 1K 또는 공유 텍스처

최종 수치는 실제 화면 크기와 모바일 성능 측정 후 조정한다.

## 3. 재질과 텍스처

단색 재질 대신 최소한 다음 맵을 사용한다.

- Base Color: 고유 색상, 손으로 그린 명암과 오염
- Normal: 갑옷 흠집, 천 주름, 피부와 석재 굴곡
- Roughness: 금속, 가죽, 천, 뼈의 반사 차이
- Metallic: 금속 영역 분리
- Ambient Occlusion: 틈과 접합부의 깊이
- Emissive: 눈, 마법, 불꽃과 룬

만화풍에서는 현실적인 재질 위에 제한된 명암 단계, 굵은 형태 변화, 선택적 외곽선과 붓 터치를 추가한다. 작은 디테일보다는 실제 전투 카메라에서 읽히는 큰 명암 덩어리와 실루엣을 우선한다.

## 4. 배경 제작 파이프라인

배경은 하나의 거대한 모델이 아니라 반복 조합할 수 있는 모듈식 세트로 제작한다.

- 바닥 타일 5~8종
- 정상 벽과 파손된 벽 변형
- 기둥, 아치, 문, 계단과 난간
- 석상, 제단과 대형 랜드마크
- 쇠사슬, 천, 해골, 촛대와 잔해
- 균열, 피, 그을음과 습기 데칼
- 연기, 먼지, 불씨와 마법 파티클

타일러블 텍스처와 트림 시트를 이용해 해상도를 절약하고, 같은 모듈에도 파손 정도, 크기, 방향과 오염을 달리해 반복감을 줄인다.

## 5. 애니메이션 개선

단순한 관절 회전 대신 다음 요소를 갖춘 전신 애니메이션을 제작한다.

- 골반과 척추에서 시작되는 무게 이동
- 어깨·팔꿈치·손목의 연쇄 동작
- 무기 제어 본과 양손 고정
- 발이 바닥에서 미끄러지지 않는 접지
- 천, 끈, 장식물의 보조 움직임
- 공격 전 준비, 타격, 회수 동작
- 피격 방향과 강도에 따른 반응

캐릭터별 최소 동작 세트는 Idle, Attack 2종, Hit 2종, Skill, Death로 구성한다. 필요하면 Dodge, Guard, Stress와 Victory를 추가한다.

## 6. Three.js 렌더링 개선

고품질 모델과 텍스처가 준비된 뒤 다음 효과를 적용한다.

- 램프 기반 셀 셰이딩 또는 선택적 외곽선
- 개선된 그림자 해상도와 접촉 그림자
- SSAO와 제한적인 Bloom
- 장면 전체 색보정
- 깊이 안개와 국소 조명
- 피격 순간 카메라 흔들림과 섬광
- 칼 궤적, 피, 먼지와 파편 파티클
- 중요한 공격의 짧은 줌과 시간 연출

후처리는 좋은 원본 모델을 돋보이게 하는 단계이며, 모델링과 텍스처 품질을 대신하지 않는다.

## 7. 권장 실행 순서

전체 캐릭터를 한꺼번에 다시 만들지 않고 버티컬 슬라이스로 품질 기준을 먼저 확정한다.

1. 로언 한 명과 성소 배경 한 구역의 최종 설정화를 만든다.
2. 로언을 새로운 고품질 모델로 제작한다.
3. 배경 한 구역을 모듈식 고품질 에셋으로 교체한다.
4. Blender 렌더에서 실루엣, 재질과 조명을 승인한다.
5. Three.js에서 셰이더, 애니메이션과 성능을 검증한다.
6. 품질 기준과 제작 시간을 기록한다.
7. 승인된 기준을 나머지 아군과 적군에 반복 적용한다.

기존 모델은 삭제하지 않고 폴백 및 비교 대상으로 유지한다. 고품질 버전은 별도 파일명과 버전으로 제작해 언제든 이전 상태로 되돌릴 수 있게 한다.

## 다음 권장 작업

첫 작업은 로언의 고품질 만화풍 설정화 제작이다. 정면·측면·후면, 얼굴과 무기 확대, 재질표를 한 장의 모델 시트로 확정한다. 이 설정화를 기준으로 스컬프팅과 리토폴로지 파이프라인을 한 번 완주한 뒤, 결과와 웹 성능이 만족스러울 때 나머지 캐릭터로 확장한다.
